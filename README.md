This is a form of mkxp-z made to take in specific changes meant for my RPG Maker projects and to bring the best of various available pull requests from the main mkxp-z. It is not meant as a serious development version of the program; just grab it and/or compile it if you need it for my projects.

Often the automated builds may just entirely fail to, y'know, build, due to problems with dependencies upstream. In that case, you'll need to <a href="https://github.com/mkxp-z/mkxp-z/wiki/Compilation">build it yourself</a>, unfortunately, after making the necessary minor changes to the libraries.

If you're here, rather than just using the Windows mkxp-z build that each of my projects comes with, well... I'd assume you probably know what you're doing. Good luck!

Almost all credit belongs to the mkxp-z team and its contributors.
